# ADR 0023：AI 漫剧独立域、双批准门与文字制作包边界

## 状态

已接受。

## 背景

小说章节需要按卷或连续剧情段改编为 AI 漫剧。改编结果既要充分利用小说素材，又不能反向覆盖小说正文、正式事实或时间线；模型生成的分集方案和完整剧本也不能在作者未确认时进入正式制作内容。

## 决定

1. 漫剧使用独立的 `ComicProject`、`ComicEpisode`、`ComicVersion` 和 `ComicScene` 领域。创建项目时只接受同一小说中未删除、无重复且目录连续的章节，并冻结章节 revision、内容 SHA-256 和来源摘要。
2. AI 生成分为 `comic_season_plan` 与 `comic_episode_script` 两类可恢复任务。两类任务都必须先展示外发范围、目标线路、预计 Token 与费用，并在作者确认后才调用模型。
3. 季方案采用后只创建候选分集大纲。单集大纲必须由作者批准后才能生成剧本；剧本必须再次由作者批准后才能物化正式场次。旧 revision、伪造来源 ID 和跨项目来源都由服务端拒绝。
4. 正式场次包含场号、内外景、地点、时间、动作、对白、旁白、画面重点、钩子和资产需求。候选版本只增不改，重新生成不会覆盖历史批准版本。
5. 制作包只读取已批准剧集，提供 Markdown、JSON 和 DOCX，并附来源、版本、校验和、AIGC 说明和发布前人工检查清单。本阶段不生成图片、音频或视频。
6. 漫剧数据进入项目归档 v10 并在恢复副本时重映射全部来源与领域 ID；漫剧操作不得写入小说正文、Canon、时间线、人物或伏笔正式表。

## 结果

作者可以按连续剧情段完成“季方案候选 → 分集大纲确认 → 完整剧本候选 → 逐集确认 → 文字制作包”的闭环，同时保留模型费用门、来源可追踪性、历史版本和小说原稿隔离。

## 回滚边界

可以隐藏工作台入口或停用两个任务处理器，已批准场次和制作包仍可只读导出。v22 表均为附加域，不允许通过回滚删除用户漫剧数据；需要降级数据库时只能先导出 v10 归档或恢复升级前备份。
