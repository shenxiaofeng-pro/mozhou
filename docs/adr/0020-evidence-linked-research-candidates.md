# ADR 0020：可回链研究候选与不可信来源边界

## 状态

已接受。

## 背景

历史重生和都市重生需要地方志、行业规则、价格与技术条件，但模型归纳可能误读材料、伪造引用或服从材料中的 Prompt 注入。研究结果也不能绕过现实资料卡的作者确认门。

## 决定

1. 研究会话先冻结已有资料或粘贴文本的快照、字符范围和 SHA-256；模型与本地规则只读取该快照。
2. 来源材料始终按不可信数据封装。AI 只返回严格结构化发现，服务端逐条验证来源、字符范围、证据原文和哈希；无效引用直接丢弃并计数。
3. 本地模式零费用运行；AI 模式在创建 Job 前展示外发范围、线路、Token 与费用，并要求明确确认。
4. 任务复用 Job/Attempt/Chunk/Artifact，允许取消、重试和 Artifact 重放。相同问题与来源集合由稳定哈希识别。
5. 冲突结论以 `conflict_key` 并列呈现，不自动裁决。每条发现先处于候选态，只有作者逐条批准才创建已确认 SourceCard。
6. 未批准发现、研究原文和模型中间结果不得进入 ContextPacket；项目归档只有显式包含关联参考资产时才携带研究来源与发现。

## 结果

研究员可以提高资料整理速度，同时每个可用结论都能回到冻结证据。模型错误、Prompt 注入和低质来源不会自动成为作品事实；代价是作者仍需完成逐条审核。

## 回滚边界

可以隐藏研究台或关闭 AI handler，手工现实资料卡与本地来源仍可使用。不得跳过引用验证、外发确认或批准门，也不得把研究候选伪装成已核验事实。
