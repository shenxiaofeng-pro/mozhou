# ADR 0018：场景情节图原创性门禁与无原句证据

## 状态

已接受。

## 背景

M6 的短语、专名、人物组合和节拍检测能阻断直接复用，但多本参考作品经过换名、同义改写或拼接后，仍可能保留相同的关键场景顺序、因果推进和人物功能关系。M13 需要加深检测，同时避免保存或展示参考原句，也不能把概率性风险提示表述为法律结论。

## 决策

1. `scene-plot-graph-v1` 只比较作者已选择并应用的抽象蓝图。候选图保存场景节点、语义标签和有向推进边；来源侧只保存区段 ID、评分摘要和证据哈希，不保存命中原句。
2. 首版采用本地、版本化、确定性规则：Unicode 规范化、中文字符 n-gram、功能词归一、节点最佳匹配、顺序 LCS、连续因果边、人物功能关系和多来源汇聚。相同输入与规则版本必须产生相同分数和证据哈希。
3. 新检查与 M6 检查合并为同一个服务端门禁。任一检查 high 都阻断章纲、正文和后续 AI 沙盘；medium 必须先读取对应报告，再由作者单独确认；high 不提供确认绕过。
4. 每个蓝图 revision 保存独立检查和发现。更新蓝图后自动生成新检查，旧报告只作审计记录，不能为新 revision 放行。
5. 风险报告固定声明其用途是创作风控，不是抄袭认定或法律结论。UI 用可横向阅读的候选场景轨道解释顺序，但不显示来源作品原句。
6. schema v18 的新增表是附加数据；项目归档 v7 保存并重映射检查、发现和确认时间，v6 及更早格式连续升级。

## 结果

- 换名或同义改写但保留场景功能与顺序的方案能够被结构信号阻断。
- 常见题材套路不会因单一相似节点直接判为 high；中风险仍保留作者复核空间。
- 生成门禁不依赖前端页面自觉，报告查看与确认具有持久审计记录。
- 参考原文继续留在隔离库，不会通过报告、归档默认视图或生成上下文泄漏。

## 回滚边界

可以通过后续规则版本回到上一组阈值，也可以暂时隐藏场景图 UI；不能删除 M6 原创性门禁、不能允许 high 人工跳过、不能把来源原句写入报告。删除 v18 表或降级 v7 归档必须通过新的显式迁移。
