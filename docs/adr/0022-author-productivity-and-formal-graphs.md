# ADR 0022：作者效率数据与正式图谱边界

## 状态

已接受。

## 背景

码字日历、批注、灵感和关系图能提高连载效率，但候选稿不能污染统计，批注不能在改稿后静默漂移，灵感或 AI 假设也不能伪装成正式人物与伏笔关系。

## 决定

1. 42 天日历只聚合非候选章节版本的有符号净字数；候选稿不改变后续正式版本的计算基线。目标读取 revision 化日目标，并保存本地时区解释。
2. 批注保存章节 revision、正文哈希、字符范围、选中文字与前后上下文。正文变化后只有目标文本唯一出现才重定位，否则标记 `stale`。
3. 灵感箱保存独立状态和标签。“准备为候选”只记录目标类型与意图，不直接创建章纲、SourceCard、人物、Canon 或时间线数据。
4. 人物关系边必须引用同项目的正式 StoryEntity，可选来源章节也必须属于该项目。伏笔图谱只读取正式 StoryThread 的埋设、回收与状态。
5. SVG 图谱必须有可访问名称和 HTML 列表回退；窄屏可隐藏视觉复杂度，但不能隐藏正式关系信息。
6. schema v21 与归档 v9 保存批注、灵感和显式关系，旧归档升级为空集合，不推断或伪造历史关系。

## 结果

效率功能与正式创作数据共享来源，但拥有清晰的统计、定位和批准边界。作者能够追踪进度与关系，又不会让未采用候选或模糊锚点污染结果。

## 回滚边界

可以整体隐藏作者工具台，新表不影响正文、版本、人物和伏笔原表。不得把候选版本计为正式码字量、自动猜测歧义批注位置，或把灵感/沙盘候选画成正式图谱节点。
