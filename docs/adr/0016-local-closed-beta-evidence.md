# ADR 0016：本地封测证据与作者主动导出

## 状态

已接受。

## 背景

M11 需要比较 AI 创作质量、人工修改、可靠性、原创性与使用体验，但小说正文、参考资料和模型 Prompt 都属于高敏感作者数据。公开源码仓库也不意味着作者同意上传作品或参与遥测。

## 决策

1. 封测报告从当前项目的本地结构化事件和状态派生，不新增云端遥测、账号或后台上传。
2. 自动统计仅包含章节数量、AI 候选/采用、人工修改比例、审校问题/接受、批准耗时、费用估算、失败/恢复和原创性阻断等聚合指标。
3. 报告不得包含作品名、正文、章纲、资料原文、Prompt、文件路径、密钥或会话令牌。项目仅用随机 ID 标识。
4. 作者可主动填写 1 至 5 分和不超过 2,000 字的反馈；这部分可能包含作者自愿输入的文字，因此导出前必须明确提示。
5. 报告只在作者点击导出时生成本地 JSON 文件。是否交给测试组织者由作者决定；产品不自动发送。
6. 封测反馈和研究事件不进入作品归档，防止作品副本无意携带研究记录；它们随本机项目生命周期保留。
7. 历史重生、都市重生和现实锚点模板只预填可编辑立项锚点，不直接调用模型，也不创建正式蓝图。

## 结果

- 作者无需提交小说即可证明十章任务是否完成，并能自行核对统计口径。
- 不同测试作者的聚合指标可以在取得其主动导出文件后离线比较。
- M11 的真实作者人数、盲评与干净机验收仍是外部发布门，代码不能伪造完成。

## 回滚边界

封测入口可以整体隐藏，删除 `beta_feedback` 与 `beta_events` 前必须另写迁移和导出提示。回滚不能把本地研究数据自动改为网络遥测，也不能把它并入项目归档。
