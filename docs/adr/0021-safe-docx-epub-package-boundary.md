# ADR 0021：DOCX/EPUB 安全包解析与纯正文往返

## 状态

已接受。

## 背景

DOCX 与 EPUB 都是 ZIP 容器，可能包含路径穿越、压缩炸弹、加密条目、宏、OLE、脚本、外部关系和 XML 实体。产品只需要可靠接续小说纯正文，不需要执行或完整保留复杂排版。

## 决定

1. 解析前统一检查文件大小、条目数、展开大小、压缩比、规范路径、重复名称、加密和软链接；任何越界都拒绝整个文件。
2. XML/XHTML 禁止 DTD 和实体。DOCX 只读取安全的 `word/document.xml` 与本地关系，拒绝宏、OLE、嵌入对象和外部关系。
3. EPUB 按 container、OPF、spine 顺序读取本地 XHTML，拒绝脚本、iframe、object、embed、远程 URL 和异常包。
4. 导入继续走既有可编辑预览和单事务确认门；确认前不写项目。
5. 导出只承诺卷章标题、段落、中文和纯正文顺序，不承诺图片、脚注、CSS 或原样式往返。生成最小合法 DOCX 与 EPUB 3，并返回 MIME、文件名、SHA-256 和卷章统计。
6. 实现使用 Python 标准库，不引入新的文档解析供应链依赖。

## 结果

作者可以用常见长篇格式接续和交付正文，同时把活动内容与复杂排版排除在可信边界之外。格式往返是语义/纯正文往返，不宣称视觉无损。

## 回滚边界

可以移除 DOCX/EPUB 入口，TXT/Markdown 导入和 Markdown 导出不受影响。不得为提高兼容性而执行宏、脚本、外链或关闭 ZIP/XML 安全限制。
