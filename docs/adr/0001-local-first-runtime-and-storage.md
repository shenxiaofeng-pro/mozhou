# ADR 0001：本地优先桌面运行时与 SQLite 主存储

> 状态：已接受
> 日期：2026-08-09

## 背景

墨舟保存长期创作正文、参考资料和模型密钥。作者首先需要可离线打开、不会因启动目录变化丢失数据的单机工作台。当前 React、Tauri、FastAPI sidecar 和 SQLite 闭环已通过本机安装包验证。

## 决定

1. MVP 采用 Tauri 桌面壳、React UI 和仅监听 127.0.0.1 的 FastAPI sidecar。
2. sidecar 由桌面进程启动、健康检查和回收，使用动态端口；M1 增加每次启动随机会话令牌。
3. SQLite 位于操作系统用户应用数据目录，是 MVP 的正文与结构化状态主存储。
4. schema 通过显式顺序迁移升级；升级前必须创建一致性备份，失败时停止启动。
5. 产品先以闭源私有 macOS 测试推进，Windows 在公开 MVP 前达到同一发布门。
6. 不建设产品自有云端服务、多人协作或自动发布。

## 结果

- 用户无需安装 Node、Python 或 Rust。
- 桌面打包必须在 macOS 和 Windows 原生环境分别验证。
- 其他本机进程不能仅凭端口调用业务 API。
- 正文是否迁移为可读文件只能由性能与可移植性证据驱动，MVP 不提前双写两套主存储。

## 回滚边界

桌面壳故障时可以保留本地 Web 开发模式，但不能改变数据目录和批准门。任何存储替换必须提供无损迁移、归档往返和旧版本拒绝写入测试。
