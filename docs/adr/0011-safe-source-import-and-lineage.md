# ADR 0011：安全资料导入、来源谱系与跨项目缓存

> 状态：已接受
> 日期：2026-08-10

## 背景

作者会导入超长参考小说、地方史料、行业资料和 PDF。文件编码、恶意 PDF、重复内容、跨项目复用和原文清理如果没有统一边界，会造成乱码入库、解析资源耗尽、来源丢失或删除不完整。

## 决定

1. TXT/Markdown 只自动接受 UTF-8、UTF-8 BOM 和 GB18030。所有导入必须先展示最多 2,000 字预览、编码、置信度、字数与 SHA-256；低置信度或疑似乱码必须由作者再次确认。
2. PDF 只接受文本型文件，限制为 25 MiB、2,000 页和 2,000 万提取字符，并限制提取膨胀率；拒绝错误魔数、加密、空文本、JavaScript、OpenAction、附加动作和 XFA。
3. 同时记录原始字节 SHA-256 与规范化文本 SHA-256。PDF 文本保存页码和字符范围；现实资料卡保存来源文件、日期、页码/字符范围、适用年代和可信度。
4. 参考小说与现实资料使用不同的全局原文表和仓储方法。现实资料导入后只生成未确认候选卡；作者确认前不能进入 ContextPacket。
5. 拆书 Map、单书 Reduce 和跨书 Fusion 以来源指纹、输入、prompt 版本、provider profile 与模型共同组成缓存身份；缓存记录所有来源作品，可跨项目复用但不能跨线路或输入误命中。
6. 清理全局原文前返回项目和缓存影响。清理后删除原文、区段与所有相关缓存；已应用蓝图和现实资料卡摘要保留为不可变、可解释快照。
7. 普通项目归档不携带全局原文。作者显式选择完整归档时才包含关联参考作品和现实资料；恢复时生成新的全局资产副本，不与现有权利声明静默合并。

## 结果

- 乱码和不确定编码不会静默进入数据库。
- 现实资料可以一次入库、多项目生成候选卡，并保留可核对的来源坐标。
- 同一长篇的已完成分析不会因换项目重复付费；删除原文后也不会残留可反推原文的派生缓存。
- 正文生成仍只能读取作者批准的抽象蓝图与现实锚点，不能读取参考原文。

## 回滚边界

界面可以暂时隐藏 PDF 或全局复用入口，但不得绕过预览确认、来源哈希、候选批准门或删除残留检查。若解析器发生安全问题，应禁用对应格式并保留原始资产只读，不得退回无边界解析。
