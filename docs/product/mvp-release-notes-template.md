## 本版可完成的创作闭环

- 从一句创意生成整书蓝图、卷纲和未来 3 至 5 章计划。
- 支持历史重生、都市重生、东方玄幻和西方奇幻的题材专属起航、生成与世界机制审校。
- 生成单章候选稿，作者确认后才写入正文。
- 多书分段拆解、原创性门禁、七维审校、局部改稿和版本回滚。
- 旧稿导入、日更看板、Markdown 导出、项目归档和恢复点。

## 隐私与数据

- 数据默认保存在本机；无账号、无自动遥测。
- API Key 使用系统密钥库；诊断包和封测报告默认不含创作内容。
- 只有作者确认外发后，明确预览的上下文才会发送给所选模型线路。

## 已知限制

- 当前正式题材为历史重生、都市重生、东方玄幻和西方奇幻；其他题材尚未提供专属规则。
- 首轮使用 OpenAI-compatible 线路；Ollama 原生体验后置。
- 沙盘输出是候选剧情和假设，不是事实或唯一预测。
