# 墨舟发布完整度开发计划

## 当前实施批次：R2 数据与桌面交付（已完成）

当前竖切：

1. 固定 OS Application Data 数据目录。
2. 旧 `.mozhou-data` 数据库无损复制迁移。
3. schema version、升级前自动备份和完整性门禁。
4. 全量验证现有作品可访问。
5. FastAPI sidecar、动态端口、健康门禁、退出回收和 macOS DMG（已交付）。
6. 完整项目归档、恢复为新副本和压缩恢复点（已交付）。

安全约束：旧库和已有备份不做自动删除；迁移、完整性检查或版本检查失败时停止启动，不以新建空库降级。

## 已交付：R1 可靠性底座

依赖顺序：

1. 项目列表仓储与 API，建立可重新找到作品的后端入口。
2. 作品书架与启动恢复，替换“退出后只剩新建作品”的断点。
3. 自动保存立即落盘接口与导航门禁，关闭丢稿窗口。
4. 全量验证与真实浏览器验收。

风险与缓解：

- 保存请求与导航并发：所有离开编辑器的动作统一等待 `flushNow()`。
- revision 冲突：保存失败不导航，保留本地草稿和现有重试入口。
- 旧测试默认没有项目列表请求：统一添加默认 mock，并新增真实书架行为测试。
- 书架加载正文导致性能回退：项目列表使用独立轻量查询和 `Project[]` 契约。
